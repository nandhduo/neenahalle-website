# neenahalle-website

Source files for [neenahalle.com](https://neenahalle.com) — the author website for Neena Halle Abdi.

## Files

- `index.html` — homepage
- `books.html` — stories page
- `about.html` — about page
- `images/` — moodboards and prose snippets
- favicon files

## Updating the site

Edit any file directly on github.com (pencil icon → commit changes). The site redeploys automatically through Cloudflare Pages within about 30 seconds.
